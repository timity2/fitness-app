# PULSE — Fitness App

Мобильное приложение для тренировок на React Native и Expo.

## Запуск

```bash
npm install
npx expo start
```

## Интеграция REST API

Список тренировок загружается GET-запросом из `https://dummyjson.com/posts?limit=35`.

- `services/api.js` — базовый URL и endpoint.
- `services/workoutApi.js` — запрос, проверка HTTP-ответа и преобразование данных API в формат приложения.
- `store/useWorkoutStore.js` — единое хранилище тренировок, состояния загрузки и ошибки, локальные операции CRUD и сохранение через AsyncStorage.
- `screens/WorkoutsScreen.js` — загрузка при открытии, состояния загрузки/ошибки/пустого списка и pull-to-refresh.
- Запросы отменяются через `AbortController` при уходе с экрана.
- Локально созданные тренировки сохраняются между запусками приложения. Старые демонстрационные записи `workout-001` … `workout-035` не дублируются с серверным списком.

## Примечание

DummyJSON предоставляет демонстрационные публикации, а не специализированный фитнес API. Поэтому заголовки публикаций используются как названия тренировок, а часть полей (например, длительность и калории) задаётся приложением как демонстрационные значения. Для реального продукта endpoint следует заменить на backend с моделью тренировок.
